# Требования преподавателя к оформлению отчёта

> Источник — устные замечания преподавателя, ранее записанные в `docs/PROMPTS_FOR_NEW_SESSION.md` (теперь в `_archive/`). Эти 32 пункта — обязательны для финального отчёта.

## Объём и структура

1. Отчёт 20–30 страниц.
2. Минимум 50% от итоговой ВКР.
3. Главы пропорциональны (баланс глав 1 и 2).
4. Структура: теоретическая + практическая.
5. Обязательный анализ всех инструментов в теоретической части (все технологии должны быть обоснованы).
6. По 2–3 подглавы на главу.
7. Выводы по главам не нумеруются.
8. ТЭО не обязательно для практики, но нам **нужно** (по индивидуальному заданию от 06.04).
9. Теоретическая глава названа по теме.
10. Практическая глава названа по теме.
11. Выводы по каждой главе, не нумерованные.
12. Только 2-й уровень вложенности (1.1, не 1.1.1).
13. Умение формулировать мысли (избегать AI-стиля).
14. Заключение — выводы по каждой из 5 задач введения.
15. Минимум 10 источников (текущий: 23 — OK).
16. Приложение не обязательно.
17. Документ не должен обрываться логически.
18. Расхождения с план-графиком допустимы (мы сменили курс на B2B 06.04).
19. Оформление как курсовая.

## Текст и формат

20. Жирный — только для глав/подглав.
21. Рисунок не больше половины страницы.
22. Списки: маркер одинаковый.
23. Нумерация только для порядка/важности.
24. Нет вложенных списков.
25. Таблицы > 1 страницы — в приложение.
26. Титул и план печатаются.
27. Упоминание рисунка/таблицы **до** объекта.
28. Заимствование из курсовой приветствуется.
29. Ежедневные записи по 2–3 дня, без воскресений и праздников (23.02, 8–9.03 — нерабочие).
30. Кавычки «ёлочки».
31. 5 задач во введении.
32. Сокращения: сначала полное название, потом аббревиатура.

## Стилевая проверка

Из [`FINAL_WRITING_STYLE_GUIDE.md`](FINAL_WRITING_STYLE_GUIDE.md) — обязательная проверка перед сдачей:

- Нет AI-маркеров: «следует отметить», «важно подчеркнуть», «таким образом», «в современном мире», «играет важную роль».
- Нет em dash (—), только en dash (–) или обычный тире.
- Кавычки только «ёлочки», не "программные".
- «Позволяет» и «обеспечивает» — каждое не чаще 10 раз во всём тексте.
- Нет 3+ подряд абзацев с одинаковым началом.
- Чередование длины предложений (короткое-длинное-среднее).
- Конкретные числа и факты из проекта, не абстрактные формулировки.
