# Выбор фронтенд-стека: сравнительный анализ

## Критерии выбора

При выборе фронтенд-стека для ИАС мониторинга туристической активности учитывались следующие критерии: зрелость экосистемы и наличие типизации (TypeScript), скорость сборки и горячей перезагрузки (HMR), возможности визуализации геоданных и временных рядов, поддержка тёмной/светлой темы, а также простота интеграции с REST API и SSE-потоками.

## Рассматриваемые альтернативы

### UI-фреймворки

| Критерий | React 18 | Vue 3 | Svelte 5 | Angular 17 |
|----------|----------|-------|----------|------------|
| TypeScript-поддержка | Нативная (JSX + TSX) | Хорошая (Composition API) | Ограниченная (runes) | Нативная (декораторы) |
| Экосистема библиотек | Крупнейшая (npm) | Средняя | Малая | Средняя |
| Компонентная модель | Функциональные + hooks | Options/Composition API | Реактивные runes | Классовые + сигналы |
| SSE/streaming-интеграция | Простая (useEffect + EventSource) | Аналогичная | Аналогичная | RxJS (сложнее) |
| Кривая обучения | Средняя | Низкая | Низкая | Высокая |

**React 18** выбран благодаря крупнейшей экосистеме компонентов, нативной поддержке TypeScript и наличию библиотек визуализации (Recharts, ECharts), а также широкой распространённости в индустрии, что обеспечивает долгосрочную поддержку.

### Системы сборки

| Критерий | Vite 7 | webpack 5 | Next.js 15 |
|----------|--------|-----------|------------|
| Холодный старт | <300 мс (ESM) | 5–15 с (bundling) | 3–8 с |
| HMR | Мгновенный (<50 мс) | 1–3 с | 0.5–2 с |
| Конфигурация | Минимальная | Сложная | Средняя (conventions) |
| SSR | Опционально | Ручная настройка | Встроенный |
| Tree-shaking | Нативный (Rollup/esbuild) | Через плагины | Встроенный |

**Vite 7** выбран за мгновенную горячую перезагрузку на основе ESM, минимальную конфигурацию и высокую скорость сборки. SSR не требуется — система является внутренним аналитическим инструментом, индексация поисковыми системами не нужна.

### CSS-фреймворки

| Критерий | Tailwind CSS 4 | CSS Modules | styled-components |
|----------|----------------|-------------|-------------------|
| Размер бандла | Минимальный (purge) | Зависит от проекта | Runtime-overhead |
| Тёмная тема | CSS variables + `dark:` | Ручная реализация | ThemeProvider |
| Производительность | Статическая генерация | Статическая | Runtime (CSSOM) |
| Консистентность | Design tokens | Нет системы | Нет системы |

**Tailwind CSS 4** обеспечивает утилитарный подход с встроенной поддержкой тёмной темы через CSS-переменные, минимальный размер бандла благодаря статическому анализу и консистентную дизайн-систему через конфигурацию токенов.

### Библиотеки визуализации

| Критерий | Recharts + ECharts | Chart.js | D3.js | Plotly |
|----------|-------------------|----------|-------|--------|
| React-интеграция | Нативная (Recharts) | Обёртка | Ручная | Обёртка |
| GeoMap (карты) | ECharts GeoMap | Нет | Да (сложно) | Mapbox |
| Временные ряды | AreaChart, LineChart | Line | Ручная | Scatter |
| Tree-shaking | ECharts (модульный) | Частичный | Нет | Нет |
| Размер бандла | ~180 КБ (оба) | ~60 КБ | ~90 КБ | ~1.2 МБ |

Выбрана комбинация **Recharts** (декларативные графики: AreaChart, BarChart, RadarChart, Treemap) и **ECharts** (GeoMap для карты отелей с tree-shaking). D3 отвергнут из-за императивного API, Plotly — из-за размера бандла.

### Управление серверным состоянием

| Критерий | TanStack React Query | SWR | RTK Query |
|----------|---------------------|-----|-----------|
| Кэширование | Автоматическое | Автоматическое | Store-based |
| Инвалидация | queryKey-based | Ручная | Tag-based |
| SSE/streaming | Поддержка | Ограниченная | Ограниченная |
| DevTools | Встроенные | Нет | Redux DevTools |
| Размер | ~13 КБ | ~4 КБ | ~30 КБ (+ Redux) |

**React Query** выбран за автоматическое кэширование, удобную инвалидацию по ключам и нативную поддержку SSE-стримов для чата с AI-агентом.

Маршрутизация реализована через **react-router-dom v7** — стандартное решение для React SPA с поддержкой вложенных маршрутов и динамических параметров (`/hotels/:id`).

## Обоснование выбора

Итоговый стек (React 18 + Vite 7 + Tailwind CSS 4 + Recharts/ECharts + React Query + react-router-dom v7) обеспечивает: мгновенную разработку (HMR <50 мс), типобезопасность (TypeScript), визуализацию геоданных и временных рядов, кэширование API-ответов, поддержку SSE-стримов для AI-чата, а также тёмную/светлую тему без runtime-накладных расходов.
