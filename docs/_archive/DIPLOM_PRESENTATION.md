# Презентация: ИАС Туризм Прибайкалья

## Определение идеи проекта

### Тема ВКР
Информационно-аналитическая система мониторинга и прогнозирования туристической активности Иркутской области

---

## 1. Практическая проблема

**Проблема:** Отсутствие централизованной системы для анализа и прогнозирования туристической активности в Иркутской области.

**Текущая ситуация:**
- Данные о туристических объектах разбросаны по разным источникам (101Hotels, афиши событий, культурные мероприятия)
- Нет единой платформы для анализа исторических данных
- Отсутствует прогнозирование загруженности и цен на жильё
- Руководителям и предпринимателям сложно принимать решения на основе данных

**Последствия:**
- Низкая эффективность управления туристическим потоком
- Потеря потенциальной выручки из-за неправильного ценообразования
- Сложности в планировании мероприятий и ресурсов

## 2. Предполагаемый результат реализации проекта

**Информационно-аналитическая система, включающая:**

### Функциональные возможности:
1. **Сбор данных** — автоматический парсинг данных с помощью 17 модулей парсеров (8 источников событий + отели + погода):
   - 101Hotels + Xotelo (отели, цены, загруженность, рейтинги)
   - 8 парсеров событий (irk.ru, culture38.ru, zeroevent.ru, kassir.ru, Культура РФ, Telegram, Яндекс Афиша, крупные события)
   - Open-Meteo API (погода)

2. **Хранение данных** — PostgreSQL 16 + Redis 7 в Docker (SQLAlchemy 2.0 + asyncpg; secrets, healthchecks, non-root)

3. **Анализ данных** — веб-интерфейс (8 страниц: Home, Chat, Analytics, Events, Map, Forecast, HotelDetail, About) с:
   - KPI метриками и статистикой по районам
   - Каталогом событий с поиском и фильтрацией
   - Тепловой картой загруженности
   - Корреляционным анализом

4. **Прогнозирование** — Ensemble (Prophet + NeuralProphet + XGBoost + LightGBM):
   - Prophet (регрессоры погоды и праздники)
   - NeuralProphet (авторегрессия и события)
   - XGBoost, LightGBM (25+ фичей, quantile regression)
   - Ensemble — адаптивные веса (RMSE 2.67, Иркутский район)

5. **AI-агент** — LangGraph: 5 tools (search_hotels, search_events, get_weather, forecast_occupancy, get_statistics), MemorySaver, SSE streaming; RAG (ChromaDB + GigaChat Embeddings)

### Технологический стек:
- **Backend:** FastAPI (Python), APScheduler
- **Frontend:** React + TypeScript + Recharts (графики) + ECharts (GeoMap на Map)
- **База данных:** PostgreSQL 16 (Docker, SQLAlchemy 2.0 + asyncpg)
- **Кэш:** Redis 7
- **Векторное хранилище:** ChromaDB (для RAG)
- **LLM:** Mistral Large (основной), 5 резервных провайдеров
- **Embeddings:** GigaChat API (Sber)
- **Прогнозирование:** Ensemble (Prophet + NeuralProphet + XGBoost + LightGBM)
- **AI-агент:** LangGraph (Command pattern)
- **Безопасность:** Rate Limiting, API key auth, CORS

## 3. Кому и в каких условиях может быть полезен результат проекта

### Целевая аудитория:

| Категория | Польза | Условия использования |
|-----------|---------|---------------------|
| **Предприниматели (владельцы отелей, кафе, экскурсий)** | Оптимизация цен, прогнозирование спроса, планирование маркетинговых кампаний | Доступ к интернету, базовый уровень цифровой грамотности |
| **Органы власти (туристические департаменты)** | Анализ туристического потока, планирование инфраструктуры, оценка эффективности мероприятий | Доступ к аналитическим отчётам, интеграция с существующими системами |
| **Туристы** | Поиск информации о событиях, прогнозирование цен, планирование поездок | Доступ к веб-приложению или мобильному приложению |
| **Организаторы мероприятий** | Анализ влияния событий на туристический поток, оптимизация расписания | Доступ к данным о прошлых мероприятиях и прогнозам |

### Условия использования:
- Веб-интерфейс доступен из любого браузера
- API для интеграции с внешними системами
- Возможность настройки параметров фильтрации и прогнозирования

## 4. Потенциальный экономический смысл проекта

### Прямая экономическая выгода:

1. **Для предпринимателей:**
   - Оптимизация цен на основе прогнозов → увеличение выручки на 10-15%
   - Снижение простоев номеров → увеличение загрузки на 5-10%
   - Пример: отель на 50 номеров, средняя цена 5000 ₽/сутки, загрузка 70% → прогнозирование может увеличить выручку на ~500 000 ₽/мес

2. **Для региона:**
   - Увеличение туристического потока благодаря лучшей информированности
   - Повышение эффективности инвестиций в инфраструктуру
   - Пример: увеличение потока на 5% при 1 млн туристов/год → доп. 50 000 туристов → доп. выручка ~2-3 млрд ₽/год

### Косвенная экономическая выгода:

1. **Снижение затрат на аналитику:**
   - Автоматизация сбора данных вместо ручного мониторинга
   - Экономия рабочего времени специалистов

2. **Улучшение планирования:**
   - Более точное прогнозирование позволяет эффективнее распределять ресурсы
   - Снижение рисков при принятии решений

3. **Повышение конкурентоспособности региона:**
   - Данные для маркетинга региона
   - Привлечение инвестиций на основе аналитики

## Ключевые аспекты для технико-экономического обоснования

### Технические аспекты:
1. **Масштабируемость** — Docker Compose (PostgreSQL 16 + Redis 7, secrets, healthchecks, non-root)
2. **Надёжность** — автоматический сбор данных (APScheduler), retry logic, graceful degradation
3. **Интеграция** — 59 API endpoints, 7 роутеров, мультипровайдерная LLM-архитектура
4. **Безопасность** — Rate Limiting, API key auth, SQL injection protection

### Экономические аспекты:
1. **Низкие затраты на инфраструктуру** — Docker-контейнеры, бесплатный Mistral API
2. **Быстрая окупаемость** - прогнозируемый ROI 6-12 месяцев для предпринимателей
3. **Мультипликаторный эффект** - польза для всех участников рынка

### Социальные аспекты:
1. **Повышение качества услуг** - данные для улучшения туристического опыта
2. **Прозрачность рынка** - доступ к информации для всех участников
3. **Цифровая трансформация** - внедрение ИИ в региональный туризм

## Заключение

**ИАС Туризм Прибайкалья** - это система, которая решает проблему отсутствия централизованной аналитики туристической активности в регионе.

**Ключевые преимущества:**
- Автоматический сбор данных из 10+ источников (APScheduler)
- Ансамблевое прогнозирование (Ensemble: Prophet + NeuralProphet + XGBoost + LightGBM, RMSE 2.67, Иркутский район)
- AI-агент: LangGraph, 5 tools, MemorySaver, SSE streaming, RAG (ChromaDB)
- 8 страниц веб-интерфейса; визуализация: Recharts + ECharts (GeoMap на Map)
- Контейнеризация (Docker Compose) и безопасность (Rate Limiting)

**Потенциальный эффект:**
- Увеличение выручки предпринимателей на 10-15%
- Увеличение туристического потока на 5-10%
- Снижение затрат на аналитику
- Повышение конкурентоспособности региона
