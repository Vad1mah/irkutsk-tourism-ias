# Презентация ТЭО: 10 слайдов

---

## Слайд 1: Титульный

**НА СЛАЙДЕ:**
- Информационно-аналитическая система мониторинга и прогнозирования туристической активности Иркутской области
- Технико-экономическое обоснование проекта
- ФИО, 2026 год

**РЕЧЬ:**
Добрый день! Представляю технико-экономическое обоснование проекта — информационно-аналитическая система для туристической отрасли Иркутской области. Это веб-сервис, который помогает туристам планировать поездки на Байкал, а бизнесу — прогнозировать спрос.

---

## Слайд 2: Проблема

**НА СЛАЙДЕ:**
- Заголовок: «Проблема»
- Туристы: информация разбросана по разным сайтам
- Бизнес: невозможно прогнозировать спрос
- Росстат: данные с задержкой 6–12 месяцев
- 2+ млн туристов в год, рост 20%

**РЕЧЬ:**
На рынке туризма Иркутской области существует проблема — нет единого источника актуальных данных. Туристы вынуждены собирать информацию с десятков сайтов. Бизнес не может прогнозировать загрузку. При этом регион посещает более двух миллионов туристов ежегодно, и рынок растёт на 20% в год.

---

## Слайд 3: Решение

**НА СЛАЙДЕ:**
- Заголовок: «Решение»
- Веб-платформа с тремя модулями:
  - Аналитика: сбор данных о ценах, загрузке, событиях
  - Прогнозы: ансамбль 4 ML-моделей
  - AI-ассистент: ответы на вопросы о регионе

**РЕЧЬ:**
Наше решение — веб-платформа с тремя модулями. Аналитический модуль автоматически собирает данные о ценах и загрузке отелей. Прогнозный модуль использует ансамбль из четырёх ML-моделей и формирует прогноз загрузки на 30–90 дней. AI-ассистент отвечает на вопросы пользователей в диалоговом режиме.

---

## Слайд 4: Целевая аудитория и монетизация

**НА СЛАЙДЕ:**
- Заголовок: «Целевая аудитория»
- Туристы: 2 млн/год → бесплатный доступ
- Бизнес: 370 организаций → 1 990 руб./мес
- Модель: SaaS (подписка)

**РЕЧЬ:**
Целевая аудитория — два сегмента. Туристы получают бесплатный доступ к публичной аналитике. Бизнес-пользователи — владельцы 370 отелей региона — платят подписку 1 990 рублей в месяц за полный доступ к прогнозам. Бесплатный тариф привлекает аудиторию, платный — монетизирует.

## Слайд 6: Технологии

**НА СЛАЙДЕ:**
- Заголовок: «Технологии»
- Backend: Python, FastAPI, APScheduler
- Frontend: React, TypeScript, Recharts + ECharts
- БД: PostgreSQL 16 + Redis 7, Docker (SQLAlchemy 2.0 + asyncpg; secrets, healthchecks, non-root)
- ML: Ensemble (Prophet, NeuralProphet, XGBoost, LightGBM)
- AI: LangGraph, Mistral Large; 5 tools (search_hotels, search_events, get_weather, forecast_occupancy, get_statistics), MemorySaver, SSE streaming

**РЕЧЬ:**
Технологический стек: backend на Python с FastAPI и APScheduler, frontend на React с Recharts (графики) и ECharts (GeoMap на Dashboard). База данных — PostgreSQL 16 (SQLAlchemy 2.0 + asyncpg) и Redis 7 в Docker (secrets, healthchecks, non-root). Прогнозирование — Ensemble: Prophet, NeuralProphet, XGBoost, LightGBM. AI-агент на LangGraph с Mistral Large: пять инструментов (search_hotels, search_events, get_weather, forecast_occupancy, get_statistics), MemorySaver, SSE streaming.
