# Задание 9. Составление резюме

## Резюме проекта

Информационно-аналитическая система мониторинга и прогнозирования туристической активности Иркутской области — это веб-сервис, созданный для решения проблемы отсутствия единого источника актуальных данных о туристическом рынке Байкальского региона. Проект направлен на цифровизацию туристической отрасли одного из ключевых туристических регионов России, который ежегодно посещает более 2 миллионов человек.

Разрабатываемый продукт представляет собой веб-платформу с двумя основными модулями: аналитическим и прогнозным. Аналитический модуль автоматически собирает данные о ценах и загрузке с агрегаторов бронирования, информацию о мероприятиях региона, погодные данные. Прогнозный модуль использует ансамбль из четырёх ML-моделей (Prophet, NeuralProphet, XGBoost, LightGBM) и учитывает 34 признака для формирования прогнозов загрузки средств размещения. Встроенный AI-ассистент на базе языковой модели позволяет получать ответы на вопросы о регионе в диалоговом режиме. Ключевые преимущества продукта — специализация на Байкальском регионе, наличие ML-прогнозирования и AI-ассистента, агрегация данных о событиях, бесплатный доступ для туристов — отличают его от существующих на рынке решений, которые либо не содержат данных по Иркутской области, либо предоставляют информацию с задержкой в несколько месяцев.

Целевая аудитория продукта включает два сегмента: туристы, планирующие поездку на Байкал (около 2 млн человек в год), и предприниматели туристической отрасли — владельцы отелей, гостевых домов, туроператоры (370 организаций в регионе). Распространение осуществляется через собственный веб-сайт по модели подписки (SaaS): бесплатный тариф для туристов и профессиональный тариф стоимостью 1 990 рублей в месяц для бизнес-пользователей.

На момент составления технико-экономического обоснования проект находится на стадии MVP: реализованы модули сбора данных, настроено хранение в облачной базе данных, работает прототип AI-ассистента. Общая продолжительность разработки — 95 дней в рамках выпускной квалификационной работы. Плановые сроки: начало — март 2026 года, защита — июнь 2026 года.

Финансирование проекта осуществляется из собственных средств. Реальные денежные затраты минимальны благодаря использованию бесплатных инструментов разработки, гранта учебного заведения на облачную базу данных и бесплатных токенов API языковой модели. Общие затраты за горизонт планирования 2 года составляют около 44 700 рублей денежных расходов и 235 200 рублей альтернативных издержек времени разработчика.

Прогноз выручки за 20 месяцев эксплуатации — 394 020 рублей при достижении 18 платных подписчиков к концу второго года. Чистая приведённая стоимость (NPV) при ставке дисконтирования 21% годовых составляет 33 087 рублей с учётом альтернативных издержек времени и 268 287 рублей при учёте только денежных потоков. Дисконтированный срок окупаемости — 1 квартал с начала эксплуатации.

Проект является экономически целесообразным: положительный NPV даже при консервативных предположениях и учёте стоимости времени разработчика подтверждает его жизнеспособность. Низкий уровень реальных инвестиций (около 100 рублей на старте) минимизирует финансовые риски. При успешной валидации MVP возможно масштабирование на другие туристические регионы России, что кратно увеличит потенциальную выручку при незначительном росте затрат. Дополнительную ценность представляет образовательная составляющая — проект реализуется как выпускная квалификационная работа и даёт опыт разработки коммерческого продукта полного цикла.
