# Описание продукта

## Информационно-аналитическая система мониторинга и прогнозирования туристической активности Иркутской области

Разрабатываемый продукт представляет собой **онлайн-сервис** (веб-приложение), предназначенный для предоставления предпринимателям в сфере туризма, органам власти и организаторам мероприятий возможности анализировать текущую туристическую активность региона и получать прогнозы на основе исторических данных. Система решает проблему отсутствия единой платформы для сбора, анализа и прогнозирования данных о туристическом потоке, загруженности средств размещения и событийной активности Иркутской области.

### Функциональные возможности

Система обеспечивает автоматический сбор и агрегацию данных из множества источников, включая информацию о средствах размещения, ценах, загруженности и культурно-массовых мероприятиях. Данная возможность реализуется через следующие функции:

- автоматический импорт данных об отелях и ценах из внешних источников;
- автоматический импорт информации о событиях и мероприятиях;
- формирование единой базы данных с историей изменений.

Система предоставляет возможность визуального анализа туристической активности. Данная возможность реализуется через следующие функции:

- формирование интерактивных дашбордов с ключевыми показателями;
- визуализация динамики загруженности отелей и цен за выбранный период;
- отображение календаря событий с фильтрацией по категориям.

Система обеспечивает прогнозирование туристической активности на основе исторических данных. Данная возможность реализуется через следующие функции:

- формирование прогноза загруженности средств размещения на заданный период;
- формирование прогноза цен на проживание с учётом сезонности и событий;
- визуализация прогнозов с указанием доверительных интервалов.

Система предоставляет возможность интеллектуального поиска информации посредством AI-ассистента. Данная возможность реализуется через следующие функции:

- обработка запросов пользователя на естественном языке;
- формирование ответов на основе накопленных данных;
- предоставление ссылок на источники использованной информации.

### Распространение и доступ

Для распространения продукта планируется использовать модель **прямой дистрибуции** через собственный веб-сайт. Выбор данной модели обусловлен несколькими факторами: целевая аудитория (предприниматели и органы власти) предпочитает работать с официальными источниками; веб-интерфейс не требует установки дополнительного программного обеспечения и обеспечивает доступ с любого устройства; модель позволяет напрямую взаимодействовать с пользователями и оперативно получать обратную связь. Дополнительно предусмотрен API для интеграции с внешними системами партнёров.

### Модель монетизации

Монетизация продукта планируется по модели **подписки на использование** (SaaS). Предполагается несколько тарифных планов:

- **Базовый** (бесплатный) — доступ к публичной аналитике и ограниченному количеству запросов к AI-ассистенту;
- **Профессиональный** (платная подписка) — полный доступ к аналитике, прогнозированию и неограниченным запросам;
- **Корпоративный** (индивидуальная стоимость) — расширенные возможности интеграции, приоритетная поддержка.

Выбор модели подписки обоснован следующими причинами: обеспечивается прогнозируемый регулярный доход; модель соответствует характеру использования сервиса (постоянный доступ к актуальным данным); низкий порог входа для новых пользователей благодаря бесплатному тарифу; возможность масштабирования дохода при росте базы пользователей.

### Поддержка пользователей

Послепродажная поддержка пользователей включает следующие направления:

- **Техническая поддержка** — обработка обращений пользователей через форму обратной связи и электронную почту в рабочее время;
- **База знаний** — раздел с документацией, инструкциями по использованию функций системы и ответами на частые вопросы;
- **Регулярные обновления** — выпуск обновлений с исправлением ошибок и добавлением новых возможностей не реже одного раза в месяц;
- **Индивидуальное сопровождение** — для пользователей корпоративного тарифа предусмотрен персональный менеджер и приоритетная обработка обращений.

### Текущая стадия разработки

На момент составления технико-экономического обоснования продукт находится на стадии **минимально жизнеспособного продукта (MVP)**. Реализованы базовые модули сбора данных (парсеры источников), настроена инфраструктура хранения данных (PostgreSQL, ChromaDB), реализован полный пользовательский интерфейс (8 страниц: Home, Chat, Analytics, Events, Map, Forecast, HotelDetail, About), модуль прогнозирования (ансамбль из 4 ML-моделей), AI-ассистент (LangGraph, 5 tools, SSE streaming), проведено тестирование (~94 unit-теста, 9 E2E-сценариев).
