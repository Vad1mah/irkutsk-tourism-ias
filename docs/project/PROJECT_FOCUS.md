| Ограничение | Влияние | Mitigation |
|-------------|---------|------------|
| Implicit profiling не 100% точен | ~35-45% error rate | Tone adaptation, не критичные решения |
| Нет A/B тестирования | Нет статистической значимости | Качественная оценка + benchmarks |
| Малый датасет событий (135) | Ограниченная генерализация | Расширение парсеров |
| Mistral vs GPT-4 | Возможно ниже точность | Сравнительный анализ |
| 1 агрегатор (101hotels) | 70-80% рынка | Достаточно для MVP |
