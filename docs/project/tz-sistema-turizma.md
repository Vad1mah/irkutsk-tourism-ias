## 3. ХАРАКТЕРИСТИКА ОБЪЕКТА АВТОМАТИЗАЦИИ

### 3.1. Краткие сведения об объекте

Объектом автоматизации является процесс мониторинга и анализа туристической активности Иркутской области.

Иркутская область - один из ключевых туристических регионов Сибири. На территории региона расположено озеро Байкал, привлекающее значительный туристический поток. Гостиничный фонд области насчитывает более 200 объектов размещения различных категорий.

В настоящее время мониторинг туристической активности осуществляется преимущественно вручную на основе отчётности средств размещения и данных Росстата. Оперативный анализ влияния мероприятий на загруженность не проводится.

### 3.2. Условия эксплуатации

3.2.1. **Существующее программное обеспечение:**
- Парсер данных 101Hotels (разработан в рамках курсовой работы).
- База данных PostgreSQL 16 с накопленными данными о средствах размещения.

3.2.2. **Существующее техническое обеспечение:**
- Персональный компьютер разработчика.
- Docker-инфраструктура (PostgreSQL 16, Redis 7).

3.2.3. **Пользователи системы:**
- Аналитики туристической отрасли.
- Сотрудники органов управления туризмом.
- Исследователи туристических потоков.

### 5.2. Оценка трудозатрат методом PERT

Для оценки трудозатрат применён метод PERT с тремя оценками:
- **O** - оптимистичная оценка (благоприятные условия)
- **M** - наиболее вероятная оценка
- **P** - пессимистичная оценка (реализация рисков)

**Формулы:**
- Ожидаемое время: **E = (O + 4M + P) / 6**
- Стандартное отклонение: **σ = (P − O) / 6**
