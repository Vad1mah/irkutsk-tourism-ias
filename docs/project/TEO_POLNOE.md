## 1. Резюме проекта

Информационно-аналитическая система мониторинга и прогнозирования туристической активности Иркутской области — это веб-сервис, созданный для решения проблемы отсутствия единого источника актуальных данных о туристическом рынке Байкальского региона. Проект направлен на цифровизацию туристической отрасли одного из ключевых туристических регионов России, который ежегодно посещает более 2 миллионов человек.

Разрабатываемый продукт представляет собой веб-платформу с двумя основными модулями: аналитическим и прогнозным. Аналитический модуль автоматически собирает данные о ценах и загрузке с агрегаторов бронирования, информацию о мероприятиях региона, погодные данные. Прогнозный модуль использует ансамбль из четырёх ML-моделей (Prophet, NeuralProphet, XGBoost, LightGBM) и учитывает 34 признака для формирования прогнозов загрузки средств размещения. Встроенный AI-ассистент на базе языковой модели позволяет получать ответы на вопросы о регионе в диалоговом режиме. Ключевые преимущества продукта — специализация на Байкальском регионе, наличие ML-прогнозирования и AI-ассистента, агрегация данных о событиях, бесплатный доступ для туристов — отличают его от существующих на рынке решений, которые либо не содержат данных по Иркутской области, либо предоставляют информацию с задержкой в несколько месяцев.

Целевая аудитория продукта включает два сегмента: туристы, планирующие поездку на Байкал (около 2 млн человек в год), и предприниматели туристической отрасли — владельцы отелей, гостевых домов, туроператоры (370 организаций в регионе). Распространение осуществляется через собственный веб-сайт по модели подписки (SaaS): бесплатный тариф для туристов и профессиональный тариф стоимостью 1 990 рублей в месяц для бизнес-пользователей.

На момент составления технико-экономического обоснования проект находится на стадии MVP: реализованы модули сбора данных, настроено хранение в PostgreSQL 16 (Docker, SQLAlchemy 2.0 + asyncpg), работает прототип AI-ассистента. Общая продолжительность разработки — 95 дней в рамках выпускной квалификационной работы. Плановые сроки: начало — март 2026 года, защита — июнь 2026 года.

Финансирование проекта осуществляется из собственных средств. Реальные денежные затраты минимальны благодаря использованию бесплатных инструментов разработки, локального стека Docker (PostgreSQL 16 + Redis 7) и бесплатного тарифа Mistral API (до 1 млрд токенов в месяц). Общие затраты за горизонт планирования 2 года составляют около 44 700 рублей денежных расходов и 235 200 рублей альтернативных издержек времени разработчика.

Прогноз выручки за 20 месяцев эксплуатации — 394 020 рублей при достижении 18 платных подписчиков к концу второго года. Чистая приведённая стоимость (NPV) при ставке дисконтирования 21% годовых составляет 33 087 рублей с учётом альтернативных издержек времени и 268 287 рублей при учёте только денежных потоков. Дисконтированный срок окупаемости — 1 квартал с начала эксплуатации.

Проект является экономически целесообразным: положительный NPV даже при консервативных предположениях и учёте стоимости времени разработчика подтверждает его жизнеспособность. Низкий уровень реальных инвестиций (около 100 рублей на старте) минимизирует финансовые риски. При успешной валидации MVP возможно масштабирование на другие туристические регионы России, что кратно увеличит потенциальную выручку при незначительном росте затрат. ## 2. Описание продукта

Разрабатываемый продукт представляет собой веб-сервис для туристов, планирующих поездку на Байкал, а также для предпринимателей туристической отрасли Иркутской области. Система позволяет анализировать туристическую активность региона, получать прогнозы загрузки и цен на основе исторических данных, а также задавать вопросы AI-ассистенту о регионе и событиях.

Система решает несколько проблем: для туристов — отсутствие единого источника информации о ценах, загрузке отелей и мероприятиях региона; для бизнеса — сложность прогнозирования спроса и ручной мониторинг конкурентов.

Основные возможности системы включают: автоматический сбор данных о ценах и загрузке с агрегаторов бронирования (101Hotels); сбор информации о событиях и мероприятиях (irk.ru/afisha, culture38.ru, zeroevent.ru); визуализацию динамики цен и загрузки; прогнозирование на основе ML-моделей; AI-ассистент для ответов на вопросы о регионе.

Для туристов сервис отвечает на вопросы: когда лучше ехать на Байкал, какие цены ожидать, какие мероприятия запланированы на выбранные даты. Для бизнеса — прогноз загрузки на ближайшие 30–90 дней, анализ сезонности, влияние событий на спрос.

Распространение продукта планируется через собственный веб-сайт. Веб-интерфейс не требует установки и доступен с любого устройства. Для бизнес-пользователей предусмотрен API для интеграции с собственными системами.

Монетизация осуществляется по модели подписки (SaaS). Предусмотрено два тарифа: бесплатный — доступ к публичной аналитике, календарю событий и ограниченному числу запросов к AI-ассистенту; профессиональный (1 990 рублей в месяц) — полный доступ к прогнозам, детальной аналитике, безлимитные запросы к AI и экспорт данных. Бесплатный тариф привлекает аудиторию, платный монетизирует бизнес-пользователей.

Поддержка пользователей осуществляется через документацию и FAQ на сайте, форму обратной связи, регулярные обновления с исправлениями и новыми функциями.

На момент составления ТЭО продукт находится на стадии MVP. Реализованы модули сбора данных (10 парсеров), настроено хранение в PostgreSQL 16 (Docker, SQLAlchemy 2.0 + asyncpg), Redis 7 для кэширования, работает AI-агент на базе Mistral Large (LangGraph), ансамблевое прогнозирование (Prophet + NeuralProphet + XGBoost).

## 3. Анализ рынка и потребностей пользователей

Разрабатываемый продукт ориентирован на рынок цифровых сервисов для туризма в Иркутской области — одном из ключевых туристических регионов России, включающем озеро Байкал. По данным Министерства туризма Иркутской области, в 2025 году регион посетило более 2 миллионов туристов, что на 20% больше, чем годом ранее. Иностранных туристов — около 70–80 тысяч человек. Рынок характеризуется устойчивым ростом.

В регионе работает 549 коллективных средств размещения: 370 гостиниц, хостелов и гостевых домов, 179 санаториев и турбаз. Средний доход одного отеля составляет 19,5 миллиона рублей в год. Большинство объектов работают круглогодично, 20% — сезонно.

На рынке отсутствуют специализированные цифровые решения для анализа туристической активности именно Байкальского региона. Существующие инструменты либо глобальные и не учитывают местную специфику, либо представляют разрозненные источники данных без комплексного анализа.

Целевая аудитория продукта включает два сегмента. Первый — туристы, планирующие поездку на Байкал (около 2 млн человек в год). Им нужно понять, когда лучше ехать, какие цены ожидать, какие мероприятия запланированы. Второй — предприниматели туристической отрасли: владельцы отелей, гостевых домов, туроператоры (около 370 организаций). Им нужен прогноз загрузки и инструменты для ценообразования.

Проблемы туристов: информация о ценах, загрузке и событиях разбросана по разным сайтам; сложно понять оптимальное время для поездки; нет единого источника актуальных данных о регионе.

Проблемы бизнеса: невозможность прогнозирования спроса на основе исторических данных; ручной мониторинг цен конкурентов отнимает время; отсутствие понимания, как события влияют на загрузку.

На рынке есть несколько продуктов, решающих похожие задачи. TravelDB — сервис аналитики для отелей с мониторингом спроса и цен (от 299 до 2 990 рублей в месяц), но без данных по Иркутской области. TravelLine — российский сервис управления отелями, ограничен данными своих клиентов. Росстат публикует статистику с задержкой 6–12 месяцев.

Недостатки: ограничение одним регионом на старте; меньший объём исторических данных по сравнению с глобальными сервисами.

## 4. Описание технологических решений

Продукт построен на клиент-серверной архитектуре. Серверная часть реализована как набор модулей на Python, клиентская — одностраничное веб-приложение (SPA) на React. Взаимодействие осуществляется через REST API.

Основные компоненты системы: модуль сбора данных — 10 парсеров получают информацию о ценах и загрузке с 101Hotels и Xotelo, о событиях — с irk.ru/afisha, culture38.ru, zeroevent.ru, kassir.ru, Культура РФ, Telegram, Яндекс Афиша; модуль хранения — PostgreSQL 16 для структурированных данных, ChromaDB для векторного поиска, Redis для кэширования; модуль прогнозирования — ансамбль ML-моделей (Prophet + NeuralProphet + XGBoost); AI-агент на LangGraph с Mistral LLM и 5 инструментами; API-сервер на FastAPI; веб-интерфейс на React.

Backend реализован на Python 3.11 с FastAPI. Для прогнозирования используется ансамбль из четырёх моделей: Prophet и NeuralProphet для анализа временных рядов с учётом сезонности, XGBoost и LightGBM для учёта дополнительных факторов (события, погода, праздники). Feature engineering включает 34 признака: календарные, праздники РФ, лаги, скользящие статистики, погода, события.

RAG-модуль построен на LangGraph для управления диалогом. Для векторизации используется GigaChatEmbeddings. Основная языковая модель — Mistral Large (бесплатный тариф до 1 млрд токенов в месяц); GigaChat — резервный LLM-провайдер. При масштабировании возможны платные тарифы Mistral/GigaChat или переключение провайдера через конфигурацию приложения.

Frontend разработан на React с TypeScript; дашборды и графики — Recharts и ECharts. Инфраструктура данных — Docker: PostgreSQL 16 + Redis 7; доступ к реляционной БД — SQLAlchemy 2.0 + asyncpg.

Горизонт планирования — 2 года: 4 месяца разработка (ВКР), 20 месяцев эксплуатация.

## 7. Оценка эффекта от реализации проекта

Продукт ориентирован на монетизацию через модель подписки (SaaS). Основной доход формируется от платных подписок бизнес-пользователей. Туристы пользуются сервисом бесплатно, создавая аудиторию и увеличивая ценность продукта для бизнеса.

Модель монетизации: бесплатный тариф — публичная аналитика, календарь событий, 5 запросов к AI в день; профессиональный тариф (1 990 рублей в месяц) — полный доступ к прогнозам, детальная аналитика по конкурентам, безлимитные запросы к AI, экспорт данных.

Целевая аудитория для платного тарифа — владельцы и управляющие средств размещения (370 объектов в регионе), турагентства и туроператоры. Консервативный прогноз: охват 5% целевой аудитории к концу первого года (18–20 организаций), 10% к концу второго года (35–40 организаций).
