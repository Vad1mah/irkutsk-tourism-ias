## Риски проекта

| Риск | Вероятность | Влияние | Стратегия |
|------|-------------|---------|-----------|
| Недоступность API (Mistral, GigaChat) | Средняя | Высокое | Переключение LLM-провайдера, локальные модели |
| Изменение структуры сайтов-источников | Высокая | Среднее | Модульные парсеры, мониторинг |
| Нехватка времени на документирование | Средняя | Высокое | Параллельное написание ВКР |
| Технические проблемы с PostgreSQL | Низкая | Высокое | Резервное копирование, тестовая БД |
