**Описание технологических решений**

Продукт построен на клиент-серверной архитектуре. Серверная часть
реализована как набор модулей на Python, клиентская - одностраничное
веб-приложение (SPA) на React. Взаимодействие через REST API.

Основные компоненты: модуль сбора данных - парсеры получают информацию о
ценах и загрузке с 101Hotels (ежедневный парсинг публичных страниц), о
событиях - с irk.ru/afisha, culture38.ru, zeroevent.ru; модуль
хранения - Yandex YDB Serverless для структурированных данных, ChromaDB
для векторного поиска; модуль прогнозирования - ансамбль ML-моделей;
RAG-модуль - AI-ассистент на базе GigaChat; API-сервер на FastAPI;
веб-интерфейс на React.

Backend реализован на Python 3.11 с FastAPI. Для прогнозирования
используется ансамбль из четырёх моделей: Prophet и NeuralProphet для
анализа временных рядов с учётом сезонности, XGBoost и LightGBM для
учёта дополнительных факторов (события, погода, праздники). Feature
engineering включает 34 признака: календарные, праздники РФ, лаги,
скользящие статистики, погода, события.

RAG-модуль построен на LangGraph для управления диалогом. Для
векторизации используется GigaEmbeddings. В качестве языковой модели -
GigaChat-2 (Lite) от Сбера. На этапе разработки и MVP используются
бесплатные токены для разработчиков. При масштабировании планируется
переход на платный тариф GigaChat API (от 1000 рублей в месяц) или на
альтернативные модели (OpenRouter, Yandex GPT).

Frontend разработан на React с TypeScript. Yandex YDB Serverless выбран
благодаря бесплатному гранту от учебного заведения и модели оплаты по
фактическому использованию.
