# Диаграмма вариантов использования (Use Case)

## Общая информация

Диаграмма Use Case описывает функциональное назначение ИАС "Туризм Прибайкалья" с точки зрения внешних актёров.

**Файлы:**
- `use_case_model.drawio` - диаграммы (7 страниц)
- `UC_SCENARIOS.md` - полные текстовые сценарии

## Актёры

| Актёр | Описание |
|-------|----------|
| Пользователь | Турист, аналитик или представитель туриндустрии. Использует систему для получения информации и прогнозов |
| Администратор | Наследует права пользователя. Управляет настройками системы и мониторит работу |
| Планировщик | APScheduler (AsyncIOScheduler). Запускает автоматический сбор данных по расписанию (события — 6ч, отели — 2ч, погода — 3ч, Telegram — 1ч) |

## Структура диаграммы (8 страниц)

1. **Общая диаграмма** - все актёры, все UC, отношения
2. **UC1** - Построить прогноз загруженности (Ensemble)
3. **UC2** - Просмотреть справочник размещения
4. **UC3** - Просмотреть календарь событий
5. **UC4** - Сравнить модели прогнозирования
6. **UC5** - Аналитика по районам (тепловая карта, radar)
7. **UC6-UC7** - Функции администратора
8. **UC8** - Автоматический сбор данных (APScheduler)

## Отношения

| Тип | Описание | Применение |
|-----|----------|------------|
| Ассоциация | Связь актёра с UC | Все основные UC |
| Extend | Условное расширение поведения | Фильтрация, визуализация, детали |
| Include | Обязательное включение | UC1 (ввод вопроса, RAG, LLM), UC7 (сбор данных) |
| Обобщение | Наследование | Администратор → Пользователь |
