# Диаграмма вариантов использования (Use Case)

## Общая информация

Диаграмма Use Case описывает функциональное назначение ИАС мониторинга и прогнозирования туристической активности Иркутской области с точки зрения внешних актёров. Система спроектирована как **B2B-инструмент** для трёх профильных сегментов рынка: отельеры, региональная администрация, исследователи.

**Файлы:**
- `use_case_model.drawio` - диаграммы (8 страниц)
- `UC_SCENARIOS.md` - полные текстовые сценарии

## Актёры

| Актёр | Описание |
|-------|----------|
| Отельер | Владелец / менеджер средства размещения (гостиница, санаторий, гостевой дом). Использует прогноз загрузки, RMS-метрики (RevPAR, ADR, Pickup, Pace) и анализ влияния событий на спрос для управления доходностью своего объекта. ~370 гостиниц + 179 санаториев в регионе. |
| Администратор региона | Сотрудник Министерства туризма / Агентства по туризму Иркутской области. Использует агрегированную аналитику по районам, отчётность по событийной активности и сравнение динамики средств размещения. |
| Исследователь | Профильный экономист, urban-аналитик, академическая группа. Использует методологию подсчёта метрик, экспорт структурированных данных и сравнение моделей прогнозирования для воспроизводимых исследований. |
| Технический администратор | ИТ-специалист, поддерживающий работу системы. Управляет источниками данных, мониторит парсеры и здоровье сервисов. |
| Планировщик | APScheduler (AsyncIOScheduler). Запускает автоматический сбор данных по расписанию (события — 6ч, отели — 2ч, погода — 3ч, Telegram — 1ч). |

## Перечень Use Cases

| ID | Название | Актёр | Include | Extend |
|----|----------|-------|---------|--------|
| UC1 | Получить прогноз загрузки объекта/района | Отельер, Администратор региона | Ввести параметры запроса, Запросить Ensemble прогноз, Визуализировать результат | Построить Ensemble прогноз (Prophet + NeuralProphet + XGBoost), Показать CI-bands, Показать метрики моделей |
| UC2 | Просмотреть карточку своего объекта размещения | Отельер | Загрузить профиль объекта, Загрузить статистику загрузки, Загрузить динамику цен | Просмотреть RMS-метрики (UC10), Просмотреть прогноз (UC1), Посмотреть на карте |
| UC3 | Анализ событий и их влияния на спрос | Отельер, Администратор региона, Исследователь | Получить календарь событий, Рассчитать impact события | Фильтровать по типу/источнику, Сортировать по impact, Просмотреть детали события |
| UC4 | Сравнить модели прогнозирования и выгрузить методологию | Исследователь | Запустить compare-all, Получить метрики (RMSE, MAE, R²) | Просмотреть feature importance, Скачать методологию (CSV), Выбрать горизонт |
| UC5 | Региональная аналитика рынка | Администратор региона | Загрузить heatmap по районам, Загрузить рейтинг RevPAR | Тепловая карта, Сравнение районов, Скачать сводный отчёт |
| UC6 | Управление источниками данных | Технический администратор | Загрузить список источников | Редактировать настройки, Проверить доступность, Перезапустить парсер |
| UC7 | Мониторинг работы системы | Технический администратор | Загрузить логи и метрики | Фильтровать по уровню, Статистика парсеров, Health-checks сервисов |
| UC8 | Автоматический сбор данных | Планировщик | Собрать события (8 источников), Собрать средства размещения (101Hotels + Xotelo), Собрать погоду (Open-Meteo), Обновить индекс ChromaDB | Уведомить Технического администратора (при ошибке) |
| UC9 | Экспорт данных для исследовательских задач | Исследователь | Запросить выгрузку через `/api/analytics/export?type=...`, Сформировать CSV, Скачать файл | Выбрать тип данных (occupancy / events / hotels), Задать диапазон дат, Указать фильтр по району |
| UC10 | Расчёт RMS-метрик: RevPAR, ADR, Pickup, Pace | Отельер | Получить агрегаты через `/api/analytics/revenue-summary`, Получить Pickup/Pace через `/api/analytics/pickup-pace`, Получить heatmap через `/api/analytics/weekday-heatmap` | Сравнить с прошлым периодом, Скачать метрики (CSV), Просмотреть тренд |

## Структура диаграммы (10 страниц)

1. **Общая диаграмма** - все актёры, все UC, отношения
2. **UC1** - Получить прогноз загрузки (Ensemble)
3. **UC2** - Карточка объекта размещения (RMS-метрики, динамика бронирований)
4. **UC3** - Анализ событий и impact
5. **UC4** - Сравнение моделей и выгрузка методологии
6. **UC5** - Региональная аналитика (heatmap, RevPAR-рейтинг)
7. **UC6-UC7** - Функции технического администратора
8. **UC8** - Автоматический сбор данных (APScheduler)
9. **UC9** - Экспорт данных в CSV
10. **UC10** - Расчёт RMS-метрик

## Отношения

| Тип | Описание | Применение |
|-----|----------|------------|
| Ассоциация | Связь актёра с UC | Все основные UC |
| Extend | Условное расширение поведения | Фильтрация, визуализация, детали, экспорт |
| Include | Обязательное включение | UC1 (параметры, Ensemble, визуализация), UC8 (сбор по источникам), UC9 (выгрузка), UC10 (агрегаты) |
| Обобщение | Наследование | Технический администратор → права на UC6, UC7 (служебная роль, не наследует B2B-функции) |
