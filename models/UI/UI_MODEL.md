# Диаграмма пользовательского интерфейса

## Назначение

Диаграмма описывает экраны (Screen) и элементы управления (UI Control) интерфейса пользователя ИАС "Туризм Прибайкалья".

## Экраны системы

| Экран | Стереотип | Описание |
|-------|-----------|----------|
| Главная страница | «web page» | Чат с AI-агентом, ввод запросов |
| Справочник размещения | «web page» | Каталог средств размещения с фильтрацией |
| Календарь событий | «web page» | Просмотр мероприятий региона |
| История запросов | «web page» | Предыдущие диалоги с агентом |
| Карточка объекта | «control» | Детали средства размещения |
| Карточка события | «control» | Детали мероприятия |
| Панель администратора | «web page» | Управление источниками, логи |

## Элементы управления

### Главная страница (UC1)
- Навигация (Panel)
- Поле ввода запроса (Text)
- Кнопка Отправить (Button)
- Область ответа (Panel)
- График прогноза (Panel)
- Ссылки на источники (List)

### Справочник размещения (UC2)
- Фильтр по району (Combobox)
- Фильтр по типу (Combobox)
- Рейтинг от-до (Slider)
- Таблица объектов (Table)
- Кнопка Применить (Button)
- Кнопка На карте (Button)

### Календарь событий (UC3)
- Календарь (Panel)
- Фильтр по типу (Combobox)
- Список событий (List)
- Кнопка Назад/Вперёд (Button)

### История запросов (UC4)
- Список запросов (List)
- Панель диалога (Panel)
- Кнопка Повторить (Button)

### Карточка объекта
- Название (Label)
- Адрес (Label)
- Рейтинг (Label)
- Кнопка Закрыть (Button)

### Карточка события
- Название (Label)
- Дата и время (Label)
- Место проведения (Label)
- Описание (Text)
- Кнопка Закрыть (Button)

### Панель администратора (UC5, UC6)
- Таблица источников (Table)
- Кнопка Редактировать (Button)
- Кнопка Проверить (Button)
- Таблица логов (Table)
- Фильтр уровня (Combobox)
- Фильтр по дате (Panel)
- Кнопка Экспорт (Button)

## Связи

| Тип | Обозначение | Применение |
|-----|-------------|------------|
| Ассоциация | Линия | Связь между экранами (навигация) |
| Вложенность | ⊕ | Control внутри web page |
