# Диаграмма предметной области (Domain Model)

## Назначение

Диаграмма предметной области описывает основные понятия (объекты) предметной области и отношения между ними. Объекты выявлены на основе анализа сценариев вариантов использования (UC1-UC8).

## Объекты предметной области

| Объект | Описание | Источник (UC) |
|--------|----------|---------------|
| Пользователь | Турист, аналитик, представитель туриндустрии | UC1-UC4 |
| Администратор | Технический специалист, наследует Пользователя | UC5-UC6 |
| Запрос | Текстовый вопрос пользователя к системе | UC1, UC4 |
| Ответ | Текстовый ответ системы на запрос | UC1 |
| AI-агент (LangGraph) | MainAgent + ForecastAgent, обработка запросов (StateGraph, Command pattern) | UC1 |
| Прогноз (Ensemble) | Ансамблевое предсказание: Prophet + NeuralProphet + XGBoost → weighted average | UC1, UC4 |
| Модель прогнозирования | Prophet / NeuralProphet / XGBoost — индивидуальная модель | UC1, UC4 |
| Метрики модели | RMSE, MAE, R² — оценка качества модели на тестовых данных | UC4 |
| Feature Engineering | Календарные, лаговые, скользящие, погодные, событийные фичи для XGBoost | UC1 |
| Погодный прогноз | Данные Open-Meteo API: температура, осадки, ветер | UC1, UC8 |
| Средство размещения | Гостиница, отель, хостел, гостевой дом | UC2, UC7 |
| Тип размещения | Классификация средств размещения | UC2 |
| Район | Территориальная принадлежность объекта | UC2 |
| Номерной фонд | Комнаты и номера средства размещения | UC2 |
| Статистика загруженности | Данные о занятости номеров по датам | UC1 (прогноз) |
| Событие | Мероприятие региона (концерт, фестиваль, выставка) | UC3, UC7 |
| Тип события | Классификация событий | UC3 |
| Календарь | Отображение событий по датам | UC3 |
| История запросов | Хранилище предыдущих запросов пользователя | UC4 |
| Источник данных | Внешний ресурс для сбора информации | UC5, UC7 |
| Лог системы | Журнал работы системы | UC6 |
| Планировщик (APScheduler) | Автоматический запуск задач по расписанию (события 6ч, отели 2ч, погода 3ч, Telegram 1ч) | UC8 |
| Векторный индекс (ChromaDB) | Эмбеддинги документов для RAG-поиска (GigaChat Embeddings) | UC1 |
| Кэш (Redis) | Кэширование API-ответов для снижения нагрузки | UC1-UC5 |

## Отношения

### Ассоциации

| Объект 1 | Отношение | Объект 2 |
|----------|-----------|----------|
| Пользователь | создаёт | Запрос |
| Пользователь | просматривает | История запросов |
| AI-агент (LangGraph) | обрабатывает | Запрос |
| AI-агент (LangGraph) | формирует | Ответ |
| AI-агент (LangGraph) | вызывает | Прогноз (Ensemble) |
| Прогноз (Ensemble) | использует | Модель прогнозирования |
| Прогноз (Ensemble) | использует | Feature Engineering |
| Прогноз (Ensemble) | учитывает | Погодный прогноз |
| Запрос | получает | Ответ |
| Прогноз | связан с | Средство размещения |
| Прогноз | учитывает | Событие |
| Прогноз | строится на основе | Статистика загруженности |
| Средство размещения | имеет | Тип размещения |
| Средство размещения | расположено в | Район |
| Событие | имеет | Тип события |
| Администратор | управляет | Источник данных |
| Администратор | просматривает | Лог системы |
| Планировщик | запускает сбор | Источник данных |
| Источник данных | предоставляет | Средство размещения |
| Источник данных | предоставляет | Событие |

### Агрегации (часть-целое)

| Целое | содержит | Часть |
|-------|----------|-------|
| Средство размещения | содержит | Номерной фонд |
| Средство размещения | содержит | Статистика загруженности |
| Календарь | содержит | Событие |
| История запросов | содержит | Запрос |

### Обобщения (наследование)

| Потомок | является | Предок |
|---------|----------|--------|
| Администратор | является | Пользователь |
