# Диаграмма бизнес-процессов (Erikson-Penker)

## Нотация

Используется расширение UML - диаграмма Erikson-Penker, применяемая в Enterprise Architect для моделирования бизнес-процессов.

### Элементы нотации

| Элемент | Обозначение | Описание |
|---------|-------------|----------|
| «event» | Параллелограмм | Событие, инициирующее процесс |
| «information» | Прямоугольник | Информация, необходимая для процесса |
| «resource» | Прямоугольник | Ресурсы (ПО, оборудование) |
| «goal» | Прямоугольник | Цель процесса |
| «output» | Прямоугольник | Результат процесса |

## Контекстная диаграмма

**Центральный процесс:** Информационно-аналитическая поддержка туризма Прибайкалья

### Входные элементы

**«event»:**
- Запрос пользователя на анализ туризма

**«information»:**
- Данные о средствах размещения
- События региона
- Исторические данные загрузки

**«resource»:**
- PostgreSQL 16 (база данных)
- AI-агент (MiMo + RAG)
- Prophet (прогнозирование)
- Веб-интерфейс (React)

### Выходные элементы

**«goal»:**
- Обеспечение качественного анализа и прогнозирования туристической сферы региона

**«output»:**
- Аналитический ответ AI-агента
- Прогноз загрузки средств размещения

## Декомпозиция

### Процесс 1: Сбор и обновление данных о туризме

| Элемент | Значение |
|---------|----------|
| «event» | Срабатывание планировщика |
| «information» | Метаданные, Внешние API |
| «resource» | PostgreSQL 16 |
| «goal» | Актуальные данные о средствах размещения и событиях |
| «output» | Обновлённые данные в PostgreSQL 16 |

### Процесс 2: Взаимодействие с пользователем

| Элемент | Значение |
|---------|----------|
| «event» | Пользователь вводит запрос |
| «information» | Запрос пользователя |
| «resource» | Веб-интерфейс, FastAPI |
| «goal» | Удобный ввод и получение ответа |
| «output» | Структурированный запрос |

### Процесс 3: Анализ данных и формирование ответа

| Элемент | Значение |
|---------|----------|
| «event» | Поступление запроса |
| «information» | Данные PostgreSQL 16, Аналитические данные |
| «resource» | AI-агент (MiMo), Chroma (RAG), Prophet |
| «goal» | Качественный анализ и точный прогноз |
| «output» | Ответ AI-агента, Прогноз загрузки |

## Связи между процессами

- Выход процесса 1 (обновлённые данные) используется как информация для процесса 3
- Выход процесса 2 (структурированный запрос) инициирует процесс 3
